iroh-live documentation

iroh-live is a Rust library and command line tool that sends live audio and video between devices over iroh. Peers dial each other by key and connect directly, with no media server in the middle. The wire protocol is Media over QUIC, and each viewer plays the rendition its link can carry.

iroh-live is an early tech preview: the API changes often, it is not on crates.io yet, and Linux is the main target. See platform support.

A quick example

With irl installed, publish the camera and microphone on one machine and watch them from another:

# machine A: prints a ticket (also as a QR code)
irl publish

# machine B
irl watch <TICKET>

# no camera? a test pattern and tone
irl publish --test-source

To use the library, add it from git and follow the library quickstart:

[dependencies]
iroh-live = { git = "https://github.com/n0-computer/iroh-live", features = ["full"] }
