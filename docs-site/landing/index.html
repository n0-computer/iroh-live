Live video between devices, peer to peer.

iroh-live sends live audio and video between devices over iroh and Media over QUIC. Peers dial each other by key, connect directly through NATs, and need no media server in the middle.

What it does

One stack, from a single camera to a room

A publisher encodes each source into a ladder of renditions. Every viewer's player picks the one its link can carry and switches without a blank frame, while a playout clock keeps audio and video in step.

Peer-to-peer live video

Each node is an iroh endpoint, addressed by its key. iroh punches through NATs and falls back to a relay that only forwards encrypted packets. Every track rides its own QUIC streams, so lost video never stalls audio.

How it fits together

Calls and rooms

One-to-one calls that ring, answer and hang up, and gossip rooms where members announce what they publish. Both are conventions over plain broadcasts, so irl call and your app interoperate.

Calls and rooms

Browser viewers via relay

Browsers cannot dial an iroh endpoint. The iroh-live relay reads a broadcast once over iroh and serves it to many viewers over WebTransport, which also spares a small publisher's uplink.

Serve browsers

Access control

A policy admits each peer by its endpoint id and grants what it may read and publish, by path. Audiences scope a broadcast to some peers, and tokens delegate rights to others.

Quickstart

Stream in a minute, embed in an afternoon

Try it with the irl command line tool, or add the library and publish a broadcast from your own program.

Add the library

iroh-live is not on crates.io yet, so it comes from git.

Cargo.toml
[dependencies]
iroh = "1.4"
iroh-live = { git = "https://github.com/n0-computer/iroh-live",
              features = ["full"] }
tokio = { version = "1", features = ["full"] }

Publish a broadcast

Bind an endpoint, start a node, publish, and print a ticket.

src/main.rs
let endpoint = EndpointConfig::from_env()?.bind().await?;
let layout = LiveLayout::default();
let node = Node::new(endpoint.clone(), layout.config());
let router = node.mount(Router::builder(endpoint)).spawn();

let broadcast = layout.publish(&node, "hello")?;
broadcast.set_video(source, VideoEncoding::ladder([
    VideoRendition::p360(), VideoRendition::p720(),
]))?;
println!("{}", layout.ticket(node.id(), "hello")?);
