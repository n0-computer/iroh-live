iroh-live API docs

The rustdoc of the library crates, built from main with every feature on. Most applications need only iroh_live, which re-exports the others. Crates and API docs explains how they fit together, and the documentation home leads to the book.

  • iroh_liveThe facade: calls, media over a subscription, and the re-exports of the crates below.
  • iroh_live_nodeThe node: route table, publications, sessions, relay links, policies and tickets.
  • iroh_live_roomsRooms: gossip membership and members-only broadcasts.
  • moq_ext_publisherLocalBroadcast: encodes sources into a ladder of renditions.
  • moq_ext_playerRemoteBroadcast and Player: rendition choice, A/V sync, recording input.
  • moq_ext_sourcesVideo and audio sources: test pattern, files, capture, push senders.
  • moq_ext_adaptiveRendition choice and decoder handover as pure state machines.
  • moq_ext_accessGrants, policies, token verifiers, the Layout trait and audiences.
  • moq_ext_jsonValueWriter: a latest-value JSON track writer.
  • moq_ext_eguiegui video views and the debug overlay.
  • moq_transport_irohMoQ sessions over iroh connections.
  • iroh_live_relayThe iroh-live relay server, as a library.
