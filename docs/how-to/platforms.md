# Platforms

Linux is the main target. These pages cover the two other platforms that
iroh-live has demos for.

- [Use iroh-live on Android](android.md): the demo app, and how its Rust core
  uses iroh-live for capture, calls and rendering.
- [Publish from a Raspberry Pi](raspberry-pi.md): the Pi camera, the V4L2
  hardware codecs, and cross-compiling.

[Platform support](../reference/platforms.md) lists what runs on each
platform, and which codec backends it has.
